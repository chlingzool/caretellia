# Caretellia

Caretellia 是一款基于 Tauri + Vue 的桌面明信片编辑器，用于创作、预览和导出节日祝福、感谢信、纪念卡等明信片内容。

## 已支持功能

- 信封 / 明信片 / 单面信纸三种模式编辑
- 支持信纸正文与明信片背面的长文富文本编辑
- 富文本工具栏会明确显示当前选区已启用的格式
- 首页入口卡片继承应用设置中的界面字体和字号
- 字体选择与本机字体读取
- 图片上传、邮票设置与卡片背景自定义
- 历史草稿保存与加载
- 历史记录详情展开、单封删除与计数同步
- HTML 导出与本地预览
- 导出的信封、明信片与信纸均在页面中居中显示，长信仍可滚动阅读
- 可拖拽调整大小的等比例编辑预览
- 信封展开预览按信件内容自动延展，不裁切长文
- 信封按“先开翻盖、再抽出信纸”的顺序展开；收起时信纸先归位，再合上信封
- 所有信件类型均可调整内容字号，信纸预览也可拖动调整浮动宽度
- 独立模板库：明信片、复古信封、单面信纸与精选文案风格
- 信纸支持上传、拖动、缩放、旋转和移除贴纸，贴纸显示在文字下方，布局可随信件保存和导出
- 信纸预览与导出使用相同画布宽度基准；画布至少保持 8:5，并随长文纵向延展
- 界面字体（读取本机字体）、字号与默认导出文件夹设置
- 导出 HTML 支持浅色、深色与跟随系统，并适配移动屏幕
- 顶部感谢菜单展示作者信息、开源依赖声明、许可证待补充说明与特别鸣谢
- 复古中性色纸张与轻微褶皱质感的信封样式

## 运行方式

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 开发建议

- 优先保留手动编辑自由度，模板仅作为快速起草入口
- 后续可继续增加导出 PDF / PNG、打印预览和更丰富的节日模板
- 历史草稿以本地存储为主，适合桌面端轻量应用场景
