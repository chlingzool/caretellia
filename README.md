# Caretellia

**Caretellia** 是一款基于 Tauri 2 与 Vue 3 构建的桌面明信片编辑器。你可以用它创作节日祝福、感谢信、纪念卡等内容，在本机预览，并导出为 CLC 或 HTML 文件。

## 功能亮点

### 编辑与排版

- 支持信封、明信片和单面信纸三种版式；信纸正文与明信片背面支持长文富文本编辑。
- 富文本工具栏会标明当前选区已启用的格式；首页入口卡片沿用应用设置中的界面字体和字号。
- 编辑预览可拖拽调整大小并保持比例；所有版式均可调整内容字号，信纸预览还可调整浮动宽度。
- 信封预览会随信件内容延展，并按“打开翻盖、抽出信纸”的顺序展开、按相反顺序收起。

### 个性化与模板

- 自定义字体、字号、卡片背景、图片和邮票；可选择本机字体。
- 在独立模板库中按明信片、信封、信纸或文案风格筛选模板；文案风格提供温柔、商务两种示例内容，可直接套用后继续编辑。
- 信纸支持上传贴纸，并可拖动、缩放、旋转或移除；贴纸显示在文字下方，布局可随信件保存和导出。

### 草稿、预览与导出

- 保存并加载历史草稿；本机历史以压缩的 CLC 数据保存在 IndexedDB 中，并在首次启动时从旧版缓存迁移。
- 默认导出自有 `.clc` 信件文件，支持从历史页导入并校验格式版本、负载长度、SHA-256 摘要和信件字段；也可选导出 HTML 并在本机预览。
- 编辑时可用“另存为”选择 CLC 或 HTML 格式及保存位置；主页“查看信封”可查看已保存信件、打开本地 CLC，并单独管理最近查看文件记录。
- HTML 导出的内容支持浅色、深色或跟随系统主题，并适配移动屏幕。
- 信封、明信片和信纸在页面中居中显示；长内容可滚动阅读。信纸画布在预览和导出时使用一致的宽度基准，基础比例至少为 8:5，并可随长文纵向延展。
