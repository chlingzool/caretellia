# Caretellia 开发文档

本目录是项目开发、构建、依赖和架构联动规则的事实入口。命令与配置以仓库当前文件为准；当实现和文档不一致时，先核对代码/配置，再同步修正文档。

## 文档导航

- [开发、运行、构建与排障](./DEVELOPMENT.md)：本地环境、命令、桌面/移动端构建和常见故障。
- [依赖清单与升级联动](./DEPENDENCIES.md)：npm/Cargo 直接依赖职责、锁文件和插件接入联动。
- [架构与跨文件修改清单](./ARCHITECTURE.md)：模块职责、数据流和修改一个功能时需检查的文件。
- [版本、CI 与发布](./RELEASE.md)：版本同步、平台工作流、应用内更新及移动端产物。

## 维护约定

涉及用户可见行为、数据格式/持久化、模块边界、依赖、构建、权限、平台支持、版本或发布流程的代码/配置变更，必须在同一变更中更新本目录中对应文档。纯重命名、格式化或不改变行为且不改变操作方式的修改通常无需改文档；应在变更说明中说明判断依据。

修改后至少核实：

1. 文档中的文件路径、命令、依赖和平台行为仍与代码/配置一致。
2. 所有相对 Markdown 链接都能解析到仓库内文件。
3. 按变更范围运行 [开发文档](./DEVELOPMENT.md#验证命令) 中适用的验证命令，并报告未能运行的验证。

AI 助手执行代码变更时，遵守仓库根目录 [Copilot 项目指令](../.github/copilot-instructions.md) 和 [文档维护指令](../.github/instructions/project-documentation.instructions.md)；需要成套梳理或更新文档时，使用 [project-docs Skill](../.agents/skills/project-docs/SKILL.md)。
